## NixNet 1.0.0-beta

This is the first beta release of NixNet.

### Highlights

- Install signed Debian APT packages into an isolated Store on Linux ARM64 and Android/Termux ARM64.
- Manage independent profiles with pinned package roots and resolved dependency closures.
- Publish only the loaded profile's commands to `PATH`.
- Apply installs, removals, profile changes, and command-link updates through recoverable transactions.
- Remove package Store artifacts when no remaining active profile needs them.
- Repair missing Store artifacts when reinstalling an enabled package.
- Handle Ctrl-C during network operations and show a compact Braille progress indicator.

### Install

```sh
curl -fsSL https://raw.githubusercontent.com/oversonv/nixnet/main/install.sh \
  | NIXNET_VERSION=v1.0.0-beta sh
```

### Supported release targets

- Linux ARM64
- Android/Termux ARM64

NixNet does not run Debian maintainer scripts, triggers, or conffile actions. See the README's package compatibility section before installing packages that depend on them.
